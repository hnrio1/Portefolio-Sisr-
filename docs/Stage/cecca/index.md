# Stage — Cabinet CECCA

**Période :** 17 novembre → 20 décembre 2025 (5 semaines)
**Lieu :** Paris

---

## L'entreprise

Le **Cabinet CECCA** est un **cabinet d'expertise comptable** structuré en société. Son activité principale est la **comptabilité, la fiscalité, la gestion sociale et le conseil** auprès des entreprises clientes.

Le cabinet utilise une infrastructure cloud **Scaleway** pour héberger ses outils métiers et accompagner ses clients dans leur transformation numérique.

---

## Missions réalisées

<div class="grid cards" markdown>

-   :material-shield-bug: __Gestion des vulnérabilités CVE__

    Analyse des CVE via l'outil Primo, nettoyage de la base (79 entrées → 42 machines), interventions à distance via **AnyDesk**, mises à jour applicatives via **winget** (Firefox, Chrome, Edge, 7-Zip).

    *Résultat : 19 machines traitées sur 42.*

-   :material-map: __Cartographie infrastructure cloud Scaleway__

    Documentation complète sur **Draw.io** : 17 containers, 16 DNS, 3 instances, 7 VPC, bases de données, IPs flexibles, 806 GB de stockage.

-   :material-language-python: __Automatisation Python d'extraction OCR__

    Développement de scripts **Python** avec **pdfplumber** + **pytesseract** pour extraire les SIREN et dates des **1341 lettres de mission clients**.

    *Résultat : 0 erreur d'extraction, 286 dates de signature récupérées sur 335.*

    [:octicons-arrow-right-24: Voir le code](scripts-extraction/README.md)

</div>
